# Project structure

The requested folder tree was omitted after the final colon, so this project starts with a small, extensible structure:

- `src/components`: reusable interface components
- `src/layouts`: shared page layouts
- `src/pages`: routed pages
- `src/content`: blog content sources
- `src/lib`: content processing and shared utilities
- `src/types`: shared TypeScript types
- `public/images`: static image assets
