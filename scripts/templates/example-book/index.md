# کتاب آزمایشی (نمونهٔ صفحهٔ کتاب‌ها)

این یک کتاب **آزمایشی** است. فقط در حالت توسعه (`npm run dev`) دیده می‌شود و در سایت نهایی ساخته نمی‌شود، چون نام پوشه‌اش با `_` شروع می‌شود.

هر کتاب یک پوشه در `content/books/` است و داخلش یک فایل `index.md` دارد. قالب آن دقیقاً مثل مقاله‌های وبلاگ است: عنوان، برچسب‌ها، پیشنهادهای جست‌وجو، کاور اختیاری (`cover.jpg`) و همهٔ قابلیت‌های مارک‌داون.

## معرفی کتاب

در این بخش دربارهٔ موضوع کتاب می‌نویسید: نویسنده، سال انتشار، ناشر و خلاصهٔ کوتاه. این متن برای آزمایش جست‌وجوی محتوا هم استفاده می‌شود؛ مثلاً عبارت `محتوا::نقل‌قول نمونه` را در کادر جست‌وجوی صفحهٔ کتاب‌ها بنویسید.

> این یک نقل‌قول نمونه از کتاب است. با کلیک روی آن، متن برای تلگرام کپی می‌شود.

برای لینک دادن به یک badge، به badge مقصد `id` بدهید و از لینک معمولی Markdown به صفحه و شناسهٔ آن اشاره کنید. خود badge لینک نیست:

```
:badge[صفحه ۲۲]{id="p22"}
[صفحه ۲۲](/books/نام-کتاب/27#p22)
```

## صفحه‌های کتاب

کتاب‌های بلند را صفحه‌صفحه بنویسید: پوشهٔ `pages/` کنار `index.md` بسازید و هر صفحه را با **شمارهٔ صفحه** نام‌گذاری کنید: `1.md`، `2.md`، `3.md` … `index.md` فقط مشخصات و معرفی کتاب است. هر صفحه آدرس خودش را دارد (`/books/نام-کتاب/۱۲`) و زیر کتاب دکمه‌های صفحهٔ قبل و بعد، ده‌تا، صدتا، هزارتا و ده‌هزارتا (فقط وقتی آن‌قدر صفحه هست) و کادر «رفتن به صفحه» نمایش داده می‌شود. در بالای هر فایل صفحه می‌توانید عنوان فصل را بنویسید:

```
---
title: فصل اول
---
```

این کتاب آزمایشی ۱۲ صفحه دارد. از صفحهٔ معرفی می‌توان با دکمهٔ «ده صفحه بعد» به صفحهٔ ۱۰ رفت.
